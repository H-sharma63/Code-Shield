# Architecture

> Generated by /map on Sunday, 19 April 2026

## Overview
Code Shield is an AI-powered, full-stack code reviewer and real-time execution engine. It allows developers to write, edit, analyze, and run code directly in the browser using a Monaco-powered editor. The system leverages large language models for code analysis and debugging, and utilizes Judge0 for multi-language code execution.

## Components

### Terminal Backend
- **Purpose:** Native PTY bridge for handling remote terminal sessions and file operations on a persistent GCP VM.
- **Location:** `terminal-backend/`
- **Key Files:** `server.js`, `lib/workspace-manager.js`, `lib/tunnel-manager.js`

### Editor Page
- **Purpose:** Main IDE interface featuring Monaco Editor, file explorer, and various analysis panels.
- **Location:** `app/editor/page.tsx`
- **Context:** `app/components/editor/WorkspaceContext.tsx`

### API Routes
- **Analyze Code:** `/api/analyze-code` - Bridges to LLMs for review and debugging.
- **Run Code:** `/api/run-code` - Interfaces with Judge0 for execution.
- **Project Persistence:** `/api/save-project`, `/api/get-projects` - Manages metadata in PostgreSQL and content in Vercel Blob.

## Data Flow
1. **Source Sync:** Files edited in Monaco are synced to the GCP VM via WebSockets on save.
2. **Analysis:** Code is sent from the frontend to the analysis API, which queries an LLM and returns actionable feedback.
3. **Execution:** Terminal commands are sent to the GCP VM; specific code run requests are sent to the Judge0 API.
4. **Persistence:** Project state is saved to the database, while large file content is stored in Vercel Blob.
