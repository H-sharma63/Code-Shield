Only if you expect 50+ concurrent users or very large monorepos (e.g. Android/iOS builds).

Optimization Tip

We'll configure the GCP VM to use Shared Package Caching. This means if 10 users all use react, we only store the actual React files once on disk, saving massive amounts of space!
