Naming Your Public URLs

Random vs. Custom-Branded Subdomains

Cloudflare Quick Tunnel (Random)
https://pizza-walrus-alpha.trycloudflare.com

Cloudflare's free "Quick Tunnels" are always random. You cannot choose the name.

× No Custom Name

✓ Extremely Stable

Localtunnel (Custom Subdomain)
https://username-project.loca.lt

Localtunnel allows you to request a specific name for free!

✓ Custom Name Support

× Occasionally Unstable

A

Use Localtunnel (loca.lt)

This lets us do username-project.loca.lt. It feels very premium, even if the service goes down once in a while.

B

Use Cloudflare (Random)

If you care more about 100% uptime than the URL name, this is the safer bet.

Why loca.lt works for you

We can write a script on the GCP VM that tries to claim username-project.loca.lt every time the app starts. If it's taken, we can append a random number (e.g. username-project-88.loca.lt).
