Manual GCP Setup Checklist

Follow these steps in the GCP Console

1. Create VM Instance

  • Name: codeshield-workspace
  • Region: us-central1 (Iowa)
  • Machine Type: e2-micro (Free Tier eligible)
  • Boot Disk:
    • Operating System: Ubuntu
    • Version: Ubuntu 22.04 LTS
    • Size: 30 GB
  • Firewall: Check both Allow HTTP traffic and Allow HTTPS traffic

2. Configure Firewall (Port 8080)

Go to "VPC Network" → "Firewall"

  • Rule Name: allow-codeshield-8080
  • Targets: All instances in the network
  • Source Filter: IP ranges → 0.0.0.0/0
  • Protocols/Ports: Specified → TCP: 8080
