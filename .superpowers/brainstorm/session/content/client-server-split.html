Who Runs What? (Execution Model)

Clarity on Client vs. Server responsibilities

The Architecture Map
User Side (Browser)
  • Visual Editor UI
  • The "Run" Button
  • Sending raw keystrokes
  • Viewing the App Preview

"I am just the remote control."

↔
Server Side (GCP VM)
  • All npm install
  • All node_modules
  • Running the Dev Server
  • Handling the Tunnel

"I am the heavy-duty engine."

✓

100% Server-Side Execution

Everything heavy runs on the GCP VM. The user's computer stays cool and doesn't need to install anything. This is why it works even on slow laptops.

Why this is the correct choice

If we ran it on the user's side (Client), we would be limited by their browser resources (like WebContainers). By running on the Server (GCP), we have zero limits and full persistence for those node_modules you mentioned.
