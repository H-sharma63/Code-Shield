Automated Lifecycle Manager

We'll write a "Manager Service" on the VM. When you click Run, the frontend sends a single API request, and the Manager handles the rest. You never type a tunnel command.

The "Magic" Part

The Manager Service will monitor the app. If the app crashes, it restarts. If the tunnel drops, it reconnects. Everything stays "steady" without you touching the terminal.
