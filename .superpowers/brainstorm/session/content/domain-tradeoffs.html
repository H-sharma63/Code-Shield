Domain Options & Trade-offs

Can we use codeshield-app.vercel.app for app previews?

Option 1: Path Proxying (Vercel Domain)
codeshield-app.vercel.app/preview/user1/3000

× Breaks Relative Paths (e.g., /logo.png)

× Breaks Hot Reload (No WebSockets)

× Vercel Timeout (5-10s limit)

This requires a complex "Proxy Middleware" that often breaks full-stack apps.

Option 2: Workspace Domain (Dedicated)
user1-3000.workspace.dev

✓ Root-level paths work perfectly

✓ Native WebSockets / Hot Reload

✓ No Vercel limits (direct to GCP)

This is how StackBlitz and Gitpod work. It's the most stable way.

Recommendation

Use Vercel for the Editor and a Dedicated Domain for App Previews. This gives the best user experience and "New Tab" stability.
