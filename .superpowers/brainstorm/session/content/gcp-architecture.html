Wildcard DNS + Caddy

Configure *.workspace.yourdomain.com to point to GCP. Caddy auto-provisions SSL. Feels exactly like Codeanywhere.

2

Cloudflare Tunnel

Easier setup (no DNS config needed). One tunnel per session. Might be slightly slower for hot reload due to proxy hops.

Why this is better than WebContainers

  • Native Linux: Runs any binary (not just WASM-compatible).
  • Real New Tab: Browser session is a standard HTTP site.
  • Persistent node_modules: npm install happens once; survives refreshes.
