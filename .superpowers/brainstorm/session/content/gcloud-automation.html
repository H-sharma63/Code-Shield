Automated GCP Deployment

Using your local gcloud CLI

1. Provision the VM (Run on your laptop)
gcloud compute instances create codeshield-workspace \
  --machine-type=e2-micro \
  --zone=us-central1-a \
  --image-family=ubuntu-2204-lts \
  --image-project=ubuntu-os-cloud \
  --boot-disk-size=30GB \
  --tags=http-server,https-server
2. Configure the VM automatically

SSH into the machine and run the setup script:

gcloud compute ssh codeshield-workspace

Once inside the VM, paste this block to setup Node, Git, and the /workspaces folder:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt-get install -y nodejs git
sudo mkdir -p /workspaces
sudo chown -R $USER:$USER /workspaces
npm install -g pm2
3. Deploy Code (Run on your laptop)

Copy your local backend code directly to the GCP VM:

gcloud compute scp --recurse ./terminal-backend codeshield-workspace:~/

Then start the server on the VM:

gcloud compute ssh codeshield-workspace --command="cd terminal-backend && npm install && pm2 start server.js"
