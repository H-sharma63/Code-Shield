The "Smart Observer" Model

The user runs commands manually (nvm, npm i, etc.). A background process on GCP "watches" for open ports and automatically handles the tunnel/nginx without the user asking.

Why this is the "Golden Path"

  • User Freedom: They can use any tool they like (npm, yarn, pnpm, nvm).
  • Zero Friction: They don't need to know how to set up Nginx or Localtunnel.
  • Steady State: Everything they install/configure on the VM stays there.
