Interactive Terminal UI

Instead of an "Auto-Run" button, we provide a real xterm.js window. The user types npm i, and we stream that text to the GCP VM in real-time.

Why this is better for developers

  • Total Control: Users can run git branch, npm run build, or any other command.
  • Standard Workflow: It feels exactly like their local VS Code terminal.
  • Live Output: They see the installation progress and error logs as they happen.
