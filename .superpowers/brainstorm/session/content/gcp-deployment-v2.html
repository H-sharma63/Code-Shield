GCP Deployment & Storage Guide

Step-by-step to a live Workspace Node

Storage Hierarchy (on GCP VM)
/ (Root)
workspaces/
user1/
portfolio-site/
├── .git/
├── node_modules/ (Persistent here)
├── package.json
└── src/
user2/
└── e-commerce-app/ ...

1. Create the VM

In GCP Console:

  • Instance: e2-micro (Free Tier)
  • OS: Ubuntu 22.04 LTS
  • Disk: 30GB Balanced Persistent Disk
  • Firewall: Allow HTTP/HTTPS

2. Prepare the Environment

Run these commands via SSH:

sudo apt update && sudo apt install git -y
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt install nodejs -y
sudo mkdir /workspaces && sudo chmod 777 /workspaces

3. Deploy Terminal Backend

  • Copy the terminal-backend folder to the VM
  • Run npm install on the VM
  • Start with PM2: pm2 start server.js

Why /workspaces?

By creating /workspaces at the root level, it stays independent of your OS user folders. Even if you update the VM, the data in this folder remains "steady" as long as you don't delete the persistent disk.
